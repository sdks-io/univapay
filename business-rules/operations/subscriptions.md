# Subscriptions

## `POST /subscriptions` (`createSubscription`)

- **loud**, state/errors: The application token's mode (live or test) differs from the transaction token's mode → 400 "PROCESSING_MODE_MISMATCH". **Do:** Use a transaction token created in the same mode as the application token that makes the charge or subscription. Also: `createCharge`. *(spec `spec/openapi.yaml`; docs `content/ja/docs/api/error/overview.md`; `createCharge.14`)*
- **loud**, account-config/errors: A charge on a recurring token exceeds the store's CVV threshold amount → 400 "RECURRING_USAGE_REQUIRES_CVV". **Do:** Ask the consumer for the CVV, PATCH it onto the token (data.cvv) and retry the charge within 5 minutes. Also: `createCharge`. *(docs `content/ja/docs/api/transaction_tokens/overview.md`; docs `content/ja/docs/api/error/overview.md`; spec `spec/openapi.yaml`; docs `content/ja/docs/api/merchant/overview.md`; `createCharge.64`)*
- **loud**, other/errors: A bank-transfer token is used for a subscription (when creating it, or as its new token) and no subscription_plan or installment_plan is specified → 400 "PAYMENT_TYPE_NOT_ALLOWED". **Do:** Use bank transfer only for one-off and recurring charges, never for subscriptions. Also: `updateSubscriptionToken`. *(docs `content/ja/docs/guide/individual/bank.md`; spec `spec/openapi.yaml`; `createSubscription.3`)*
- **loud**, other/errors: The subscription has a subscription_plan and the token's payment method is not allowed for that plan → "SUBSCRIPTION_PAYMENT_TYPE_NOT_ALLOWED_FOR_PLAN". **Do:** Use a token whose payment method the subscription plan allows before creating the subscription or replacing its token. Also: `updateSubscriptionToken`. **Conflict:** The definition does not list which payment methods each plan allows. In test mode a konbini token of type subscription with a fixed_cycles subscription_plan was accepted (201), so konbini is allowed with that plan at least in test mode. *(spec `spec/openapi.yaml`; docs `content/tested/sandbox-api-behaviour.md`; `createSubscription.5`)*
- **loud**, other/errors: The subscription has an installment_plan and the token's payment method is not allowed for installments → 400 "INSTALLMENT_PAYMENT_TYPE_NOT_ALLOWED_FOR_PLAN". **Do:** Use a card token for installment-plan subscriptions and check the payment method before sending the request. - **loud**, other/errors: The transaction token is a one-time token rather than a subscription or recurring token (tested on POST /subscriptions with a one-time konbini token) → 400 "NOT_SUBSCRIPTION_TOKEN". **Do:** Create the token with type subscription or recurring before using it for a subscription.
